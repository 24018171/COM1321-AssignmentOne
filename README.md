# BRIGHT FUTURE TECHNOLOGIES APPLICATION

## Student Number: 24018171

## Project Description
This is a Java console application for managing electronic products for Bright Future Technologies. It allows the user to capture, search, update, delete and report on products.

## Features
1. Capture a new product - Code, Name, Category, Warranty, Price, Stock, Supplier
2. Search for a product by product code
3. Update product warranty, price and stock
4. Delete a product by code
5. Print full report with total count, total value and average value
6. Exit application

## Product Categories
- 1: Desktop Computer
- 2: Laptop
- 3: Tablet
- 4: Printer
- 5: Gaming Console

## How to Run
1. Open the project in NetBeans
2. Run JavaApplication2.java
3. Enter 1 to launch menu
4. Select options 1-6 from the menu

## Classes
- **ReportData.java** - Stores product details with getters and setters
- **Products.java** - Contains all methods: Capture, Search, Update, Delete, Print Report
- **JavaApplication2.java** - Main class with menu loop
